# Oficina — Gestão de Marcenaria

Primeira versão visual do site, criada em HTML, CSS e JavaScript, sem dependências externas.

## Arquivos
- `index.html` — estrutura do site
- `style.css` — identidade visual e responsividade
- `script.js` — navegação e conteúdo inicial

## Como publicar no GitHub Pages
1. Envie os três arquivos acima para a raiz do repositório.
2. Abra **Settings > Pages** no GitHub.
3. Em **Build and deployment**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em **Save**.
4. Aguarde a publicação. O endereço normalmente será `https://SEU-USUARIO.github.io/oficina-marcenaria/`.

**Atenção:** esta versão contém apenas dashboard inicial e navegação. Não há banco de dados, autenticação ou cadastros funcionais. Não use para dados reais de clientes nesta etapa.
