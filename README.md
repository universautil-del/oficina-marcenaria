# Oficina — Gestão de Marcenaria v0.2

Site estático para GitHub Pages. Contém dashboard e cadastro de clientes com pesquisa, edição, exclusão e backup JSON.

## Publicação
Envie `index.html`, `style.css` e `script.js` à raiz da branch `main` do repositório GitHub. Em Settings > Pages, selecione Deploy from a branch, main, /(root).

## Atenção
Os clientes são salvos apenas no localStorage do navegador. Não há login, servidor, banco de dados compartilhado ou sincronização. Faça backups regulares e evite dados reais sensíveis até implementar segurança adequada. Outros módulos ainda são telas de planejamento.
